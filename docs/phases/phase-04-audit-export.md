**Goal:** Manager can generate a professional audit-ready PDF for any application. This PDF is what a farm operator would hand to an EPA inspector. It must look real and complete.

### API Route: src/app/api/export/[id]/route.ts

```typescript
// GET /api/export/[id]
// Auth: manager role required
// Rate limit: 30 requests per hour per user

// Steps:
// 1. Auth check (manager)
// 2. Rate limit
// 3. Fetch application by id with ALL joins:
//    profiles, fields, operations, products, weather_snapshots
// 4. Verify application.operation_id = manager's operation_id (404 if not)
// 5. Run renderToBuffer() from @react-pdf/renderer with AuditPDF component
// 6. Return PDF binary

// Response headers:
// Content-Type: application/pdf
// Content-Disposition: attachment; filename="FieldLog-Audit-[applicationId].pdf"

// Error responses:
// 401: Unauthorized
// 404: Not found (also for wrong operation)
// 429: Too many requests
// 500: Internal server error (generic message only)
```

## Module 4.2 — Wire Export Button to API

In the ApplicationDetail component (built in Phase 3), the "Download Audit PDF" button must be wired to GET /api/export/[id].

```typescript
// Button handler:
const handleExport = async () => {
  setExporting(true)
  try {
    const response = await fetch(`/api/export/${applicationId}`)
    if (!response.ok) throw new Error('Export failed')
    const blob = await response.blob()
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = `FieldLog-Audit-${applicationId.slice(0, 8)}.pdf`
    a.click()
    URL.revokeObjectURL(url)
  } catch (err) {
    // Show inline error -- no alert()
    setExportError('PDF generation failed. Please try again.')
  } finally {
    setExporting(false)
  }
}
```
